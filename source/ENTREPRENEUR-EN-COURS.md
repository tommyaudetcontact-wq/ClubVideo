# Entrepreneur et catalogue fictif — travail en cours

Sauvegarde de développement du 18 novembre 2026. La page de téléchargement publique reste sur sa version précédente.

- Catalogue de 200 films fictifs, 800 textures (face, dos, tranche, disque).
- Les bandes-annonces réelles restent uniquement en lecture de fond.
- Mode entrepreneur séparé : commandes, colis, assemblage des étagères, placement assisté, inventaire, réservations et journées de huit minutes.
- Les retours doivent être scannés. Localisation jaune des exemplaires dans la boutique.
- Correction d’une erreur de prise de monnaie coop après le départ du client.
- Tests automatisés de journée, paiement, disques, coop et sauvegarde, plus simulation de 400 journées d’économie.

Les rapports dans validation-entrepreneur indiquent précisément les scénarios exécutés. Les tests de FPS et de lisibilité dans un Quest porté restent à réaliser ; aucun minimum de FPS réel n’est certifié par ces simulations. Une APK de diagnostic distincte est installée sur le casque pour ces essais. La version publique n’est pas remplacée par cette branche.

À terminer avant publication : validation Quest portée, revue des affiches posables et des interactions entrepreneur, validation du mode entrepreneur en coop, APK finales des deux plateformes. Les tests utilisent un dossier utilisateur isolé pour préserver les parties normales.
