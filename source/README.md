# Sources de Vidéo Club
Ces fichiers permettent de consulter les scripts et de suivre leur évolution. Pour rouvrir les deux projets Godot complets, utilise l’archive source de la release. Elle inclut les médias, les extensions et les ressources qui ne sont pas dupliqués dans Git.
Les chemins de modèles d’export Android et Windows sont propres au poste de développement. Sélectionne les modèles Godot 4.7.2 et ton SDK Android dans l’éditeur si tu reconstruis les APK sur un autre ordinateur.
