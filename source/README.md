# Sources de Vidéo Club
La sauvegarde complète de référence est l’archive source 0.6.5. Pour reconstruire la 0.9.8, applique le dossier videoclub-quest de ce dépôt par-dessus celui de l’archive. Le même projet Godot donne les APK Quest et Android tactile via leurs presets d’export.
Les chemins des modèles d’export sont propres au poste de développement. Sélectionne Godot 4.7.2 et ton SDK Android dans l’éditeur pour reconstruire les APK.
