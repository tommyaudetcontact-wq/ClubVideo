TÉLÉPHONE · COOP

Android

Le poste de gestion tactile. Consulte les clients, les tâches et les retours en direct, puis aide à la caisse.

Télécharger l’APK Android

Jouer ensemble

  1. Installe l’APK Quest avec ADB ou SideQuest, puis ouvre le jeu dans Sources inconnues.
  2. Installe l’APK Android sur le téléphone. Connecte le téléphone et le Quest au même Wi-Fi.
  3. Sur l’ordinateur de caisse, ouvre Coop Wi-Fi et démarre la partie locale.
  4. Sur Android, saisis l’adresse IP et le code affichés dans le casque.
